# OpenPDF Studio identity

## Forest & Paper

OpenPDF Studio pairs a rich forest-green accent with warm ivory surfaces, a native Mac typeface for controls, and an editorial serif for document-oriented display text. Slate, Cobalt, and Clay are alternate workspace palettes. Light and dark modes keep the document itself unchanged.

The generated icon uses a folded ivory page and an open green loop. The app uses the same mark in the macOS bundle, title bar, welcome screen, and Settings.

## Assets

- `brand/icon-source.png`: original generated 1254 × 1254 PNG, with alpha.
- `build/icon.png`: 1024 × 1024 macOS packaging source, with alpha. Electron Builder generates the `.icns` resource.
- `src/assets/app-icon.png`: 256 × 256 renderer asset, imported by Vite so it is bundled in production.
- `build/icon.svg`: retained legacy 0.1 icon; no longer used by the app.

Generated with the built-in image-generation tool on 2026-08-28. The original was preserved; macOS `sips` produced the two resized PNGs without changing the design.

## Generation prompt

Create one premium macOS application icon for OpenPDF Studio, an independent, beautifully crafted offline PDF editor. No words, letters, or text. Square 1024x1024 composition. A single elegant dimensional ivory sheet of paper, subtly folded at the upper right, intersected by a sculptural emerald-green open loop/arch that suggests an open document and freedom. The mark must be extremely simple and recognizable at 32 pixels: large continuous silhouette, clean negative space, no tiny details, no decorative lines or confetti. The mark sits on a rich deep forest-green rounded-square enamel tile with carefully controlled softly lit bevels, a gentle upper-left studio light, restrained dimensional materials, and exceptionally precise geometry. Think Apple macOS system icon craftsmanship and a sophisticated productivity brand. Calm, confident, timeless, not a gaming icon and not a generic red PDF icon. Ivory, deep forest green, and a subtle fresh chartreuse edge highlight only. Straight-on view, centered. Rounded square tile occupies about 88% of the canvas, transparent background outside the tile, modest physically plausible soft shadow under the tile. Deliver only the finished app icon artwork.
